# Changelog

All notable changes to Mixdeck are documented in this file.

The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project follows [semantic versioning](https://semver.org/).

There is no published release yet. The assembly version in `Directory.Build.props` is 0.1.0.
GitHub Releases are created only when a `v*` tag is pushed, and that tag needs a matching `## [X.Y.Z]` section below.

## [Unreleased]

### Added

- macOS app (`Mixdeck.Desktop`, Avalonia) beside the Windows WinUI app. System devices, the default device, volume, and mute use Core Audio. Per-app volume and routing stay unavailable. Global hotkeys use Carbon, and the foreground app uses `NSWorkspace`. FL Studio uses Core MIDI. Voicemeeter stays Windows-only; `--demo` still runs the simulator. Login items are a LaunchAgent for installed builds. `build/pack.sh`, `build/install.sh`, and the macOS CI job package the app. `Mixdeck.Portable.slnx` is the solution that job builds.
- Voicemeeter client for Standard, Banana, and Potato: a dedicated thread, a merged command queue, change-driven reads, 60 Hz meters only while a meter is visible, automatic reconnect, and a simulated engine (`--demo`, `--demo=standard`, `--demo=potato`).
- Core: atomic JSON settings with a backup copy, profiles with gain fades, per-application rules, and meter ballistics.
- Windows services: global hotkeys and push-to-talk, process and foreground detection, start with Windows, taskbar placement, single instance.
- WinUI 3 interface: taskbar flyout, console (Mixer, Routing, Profiles, Rules, Settings, About), tray icon that turns red while the microphone is muted, OSD.
- Tray icon kept visible once (if you hide it behind the chevron afterwards, it stays there), middle-click to mute, detailed tooltip.
- Mouse wheel on a flyout row changes that row's volume.
- Per-application volume in the flyout, and "Send to…" to pick an application's output (undocumented Windows API, disabled automatically if it disappears).
- Devices page: physical inputs and outputs (Windows microphones are offered when Voicemeeter lists none), microphone presets, audio-engine restart, Voicemeeter window hidden when Mixdeck launches it.
- Automatic ducking of one input when another has signal (threshold, amount, attack, hold, and release).
- Console layout: strips wrap, readable header, Mute and Solo side by side, pan on one line, readable A1…B3 sends, collapsible EQ. Only strips tied to a device are shown (plus virtual strips); `+` adds a hidden strip.
- "Hear myself" sends the microphone to a chosen bus (A1 by default).
- Optional always-on "microphone muted" badge and confirmation sound.
- "Apply a profile" hotkey and a profile applied at startup.
- Local crash log (`logs\crash-*.txt`) and a single automatic restart. The start-with-Windows entry is removed on uninstall.
- Optional Azure Trusted Signing on publish (`docs/SIGNATURE.md`).
- English and French UI. Windows display language by default, or an explicit choice in Settings.
- One-click install from source (`Installer Mixdeck.cmd`): .NET SDK and Voicemeeter installed when missing, then a Velopack package installed or updated. `build/pack.ps1` accepts `-SkipTests` and `-OutputDir`.
- `MIXDECK_DATA_DIR` overrides the data folder. Development arguments `--flyout` and `--page=<name>`.
- FL Studio control through loopMIDI and `fl/Mixdeck/device_Mixdeck.py`: FL Studio page, quick effect picks in the flyout, FL state inside profiles, slot and track hotkeys, simulated FL in demo mode. The installer can install loopMIDI, create the two ports, copy the script, and write FL's MIDI settings while FL is closed.
- Default Windows output and input from the flyout and the Devices page.
- A profile applied before FL is connected (a rule on FL launch) applies its FL state once the script answers.
- "VU meter M" logo. Icons are regenerated by `design/logo/build.py`.
- GitHub Actions CI: restore, Release build, and unit tests on `windows-latest`. FlaUI UI tests are local only (`MIXDECK_UI_TESTS=1`); they are not part of CI.
- Velopack publish on `v*` tags (package id `MixdeckApp`, settings stored apart from the install, deltas from the previous release, notes taken from this file).
- Local `build/pack.ps1` and the `vpk` 1.2.161 manifest.
- Automatic update check on startup for installed builds when Settings > Check for updates is on. The About page can still check by hand when the switch is off.
- Public docs: English README, `README.fr.md`, `SECURITY.md`, `CONTRIBUTING.md`, `NOTICE`, and issue templates.

### Fixed

- Rules that fire while Voicemeeter is closed are applied when it returns.
- A profile fade no longer delays microphone mute or later rules. A new profile interrupts the fade in progress.
- Settings restored from the backup are kept even if the main file cannot be rewritten.
- The console is created on first open and its pages are unloaded on close (about 115 MB at startup instead of 208 MB).
- Closing the console no longer exits the application. A console minimized by Windows at launch is brought back on screen.
- Quitting during automatic ducking no longer leaves music ducked. After a reconnect, music is not ducked twice.
- An incomplete settings file (missing or null sections) no longer prevents startup.
- The console wheel changes a fader only after that fader has been clicked.
- Console meters no longer stay stuck at −60 dB after the window is minimized and restored.
- Per-app session labels follow the UI language. The list is sorted with the active culture.
