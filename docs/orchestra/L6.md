# L6 — Outillage : CI, empaquetage Velopack, documentation
Agent : Grok 4.7 (Grok Build, worktree du pont `grok/*`)

## Objectif
Tout ce qu'il faut pour construire, tester et publier Mixdeck : CI GitHub Actions, release Velopack sur tag `v*`
avec mises à jour delta depuis GitHub Releases, script d'empaquetage local, README, CHANGELOG, LICENSE, .editorconfig.

## Contexte utile
- Dépôt : solution `Mixdeck.slnx` ; appli `src/Mixdeck.App/Mixdeck.App.csproj` (WinUI 3 non empaquetée, x64,
  `AssemblyName` = Mixdeck, Windows App SDK embarqué) ; bibliothèque `Velopack` 1.2.161 côté appli.
- SDK : `global.json` impose .NET SDK 10.0.403 (roll-forward latestFeature). Sur cette machine le SDK est dans
  `%USERPROFILE%\.dotnet\dotnet.exe` (le `dotnet` du PATH n'a pas de SDK) : utilise ce chemin complet localement.
- Dépôt GitHub : `https://github.com/Anarchiejs/Mixdeck`.
- Plan complet : `.orchestra/PLAN.md` monté dans le worktree.

## À réaliser
1. `.github/workflows/ci.yml` : sur push et pull_request ; `windows-latest` ; `actions/setup-dotnet` avec
   `global-json-file: global.json` ; cache NuGet ; `dotnet restore`, `dotnet build -c Release`, `dotnet test -c Release`
   (les tests n'ont pas besoin de Voicemeeter) ; résultats de tests publiés en artefact.
2. `.github/workflows/release.yml` : sur tag `v*` ; version = tag sans « v » ;
   `dotnet publish src/Mixdeck.App/Mixdeck.App.csproj -c Release -r win-x64 --self-contained -p:Version=<v> -o publish` ;
   outil `vpk` installé via le manifeste local ; `vpk download github` (release précédente, pour les deltas) ;
   `vpk pack --packId Mixdeck --packVersion <v> --packDir publish --mainExe Mixdeck.exe --packTitle Mixdeck --icon src/Mixdeck.App/Assets/Mixdeck.ico` ;
   `vpk upload github --repoUrl … --publish --releaseName "Mixdeck <v>" --tag v<v> --token ${{ secrets.GITHUB_TOKEN }}` ;
   `permissions: contents: write`. Notes de version extraites de la section correspondante de CHANGELOG.md.
3. `.config/dotnet-tools.json` : outil `vpk` épinglé (même version que la bibliothèque Velopack : 1.2.161 si elle
   existe sur nuget.org, sinon la plus proche et dis-le).
4. `build/pack.ps1` (PowerShell 5.1 compatible) : `-Version 0.1.0 [-SkipPack]` ; trouve le SDK (`%USERPROFILE%\.dotnet`
   puis PATH) ; restore des outils, tests, publish, `vpk pack` local vers `artifacts/` ; sortie claire ; code de retour ≠ 0 en cas d'échec.
5. `README.md` (français) : ce qu'est Mixdeck, fonctionnalités (panneau rapide, console, routage, profils avec
   fondu, règles par application, raccourcis + push-to-talk, OSD, mises à jour), emplacement pour captures
   (`docs/images/…`), prérequis (Windows 10 19041+/11, Voicemeeter Banana installé — la DLL de VB-Audio n'est pas
   redistribuée), installation, compilation depuis les sources (SDK 10, commandes), mode `--demo`, emplacement des
   journaux `%LOCALAPPDATA%\Mixdeck\logs`, architecture (4 projets), licence. Pas d'affirmation non vérifiable.
6. `CHANGELOG.md` (format Keep a Changelog, français) avec `## [Non publié]`.
7. `LICENSE` : MIT, « Copyright (c) 2026 Les contributeurs de Mixdeck ».
8. `.editorconfig` : C# (indentation 4, `file_scoped` namespaces, `var` quand évident, conventions .NET), XAML /
   JSON / YAML 2 espaces, fins de ligne CRLF pour .ps1.
